# Пояснения по лабораторной работе №25

В этой работе мы обрабатываем текстовые данные. Строка в языке C – это массив символов, который заканчивается нулевым символом `'\0'`. Мы будем считывать строку функцией `fgets` (она читает строку целиком, вместе с пробелами) и пользоваться функциями из библиотеки `string.h`: `strlen`, `strcpy`, `strcat`, `strchr`, `strstr` и другими.

## Что нужно прочитать перед началом:
1. Строки в языке C и нулевой символ
2. Функции библиотеки `string.h`
3. Ввод строки функцией `fgets`

> [!NOTE]
> Вхождения ищутся слева направо без перекрытия: в строке «aaa» подстрока «aa» найдётся один раз. Подстрока не должна быть пустой.

Итак, разберём код решения:
```c
#include <stdio.h> // Подключение библиотеки для ввода/вывода
#include <string.h> // Подключение библиотеки для работы со строками
#include <windows.h> // Подключение модуля windows.h для установки кодировки вывода

int main() { // Объявляем главную функцию
    SetConsoleOutputCP(CP_UTF8); // Устанавливаем кодировку UTF-8 для вывода русских символов в консоль
    char text[256]; // Объявляем строку для ввода (до 255 символов)
    char result[1024]; // Объявляем строку для результата
    char part[256]; // Объявляем строку для подстроки

    printf("Введите строку: "); // Запрашиваем строку
    fgets(text, sizeof(text), stdin); // Считываем строку целиком, вместе с пробелами
    text[strcspn(text, "\n")] = '\0'; // Убираем из строки символ перевода строки
    printf("Введите подстроку: "); // Запрашиваем подстроку
    fgets(part, sizeof(part), stdin); // Считываем подстроку
    part[strcspn(part, "\n")] = '\0'; // Убираем из подстроки символ перевода строки

    int partLength = strlen(part); // Находим длину подстроки
    if (partLength == 0) { // Проверяем, что подстрока не пустая
        printf("Подстрока не должна быть пустой.\n"); // Сообщаем об ошибке
        return 1; // Завершаем программу с кодом ошибки 1
    }

    result[0] = '\0'; // Делаем результат пустой строкой
    char *position = text; // Откуда продолжаем поиск
    char *found = strstr(position, part); // Ищем первое вхождение подстроки
    while (found != NULL) { // Пока вхождения находятся...
        strncat(result, position, found - position); // ...копируем часть строки до вхождения
        strcat(result, part); // ...записываем подстроку
        strcat(result, part); // ...и ещё раз
        position = found + partLength; // Продолжаем поиск после вхождения
        found = strstr(position, part); // Ищем следующее вхождение
    }
    strcat(result, position); // Дописываем остаток строки

    printf("\nРезультат: %s\n", result); // Выводим результат

    return 0; // Завершаем программу с возвращением 0
}
```

> [!IMPORTANT]
> Если Вы используете не Windows, а, например, macOS, то проблем с кодировкой быть не должно – в таком случае игнорируйте следующие строки:
> ```c
> ...
> #include <windows.h> // Подключение модуля windows.h для установки кодировки вывода
> ...
>      SetConsoleOutputCP(CP_UTF8); // Устанавливаем кодировку UTF-8 для вывода в консоли русских символов: иначе будут иероглифы
> ```
>
> В операционных системах семейства Linux могут быть свои заморочки с кодировкой. Если что-то работает не так, как ожидается, то заглядывайте в Google :)
