# Пояснения по лабораторной работе №27

В этой работе мы учимся работать с файлами. Файл открывается функцией `fopen` (режим `"wb"` – запись, `"rb"` – чтение, `"ab"` – дописывание в конец), компоненты записываются функцией `fwrite` и читаются функцией `fread`, а в конце файл закрывается функцией `fclose`.

## Что нужно прочитать перед началом:
1. Типы `FILE *` и функция `fopen`
2. Функции `fread`, `fwrite`, `fgetc`, `fputc`
3. Двоичные и текстовые файлы

> [!NOTE]
> Типизированный файл в языке C – это двоичный файл, в который компоненты записываются функцией `fwrite` и читаются функцией `fread`. Чтобы программу можно было проверить, она сама создаёт файл f.dat из данных, введённых с клавиатуры, а затем обрабатывает его. Результирующие файлы после записи читаются обратно и выводятся на экран.

> [!NOTE]
> Символы добавляются в конец файла режимом открытия `"ab"`, после чего файл читается и выводится.

Итак, разберём код решения:
```c
#include <stdio.h> // Подключение библиотеки для ввода/вывода
#include <string.h> // Подключение библиотеки для работы со строками
#include <windows.h> // Подключение модуля windows.h для установки кодировки вывода

int main() { // Объявляем главную функцию
    SetConsoleOutputCP(CP_UTF8); // Устанавливаем кодировку UTF-8 для вывода русских символов в консоль
    char line[256]; // Объявляем строку для символов файла
    printf("Введите символы файла f: "); // Запрашиваем символы файла
    fgets(line, sizeof(line), stdin); // Считываем строку целиком
    line[strcspn(line, "\n")] = '\0'; // Убираем символ перевода строки
    FILE *f = fopen("f.dat", "wb"); // Создаём файл f для записи
    fwrite(line, 1, strlen(line), f); // Записываем символы в файл
    fclose(f); // Закрываем файл

    f = fopen("f.dat", "ab"); // Открываем файл f для дописывания в конец
    fputc('e', f); // Дописываем «e»
    fputc('n', f); // Дописываем «n»
    fputc('d', f); // Дописываем «d»
    fclose(f); // Закрываем файл

    int symbol; // Читаемый символ
    f = fopen("f.dat", "rb"); // Открываем файл f для чтения
    printf("\nФайл f: "); // Выводим подпись
    while ((symbol = fgetc(f)) != EOF) { // Читаем символы файла
        putchar(symbol); // Выводим символ
    }
    printf("\n"); // Переходим на новую строку
    fclose(f); // Закрываем файл

    return 0; // Завершаем программу с возвращением 0
}
```

> [!IMPORTANT]
> Если Вы используете не Windows, а, например, macOS, то проблем с кодировкой быть не должно – в таком случае игнорируйте следующие строки:
> ```c
> ...
> #include <windows.h> // Подключение модуля windows.h для установки кодировки вывода
> ...
>      SetConsoleOutputCP(CP_UTF8); // Устанавливаем кодировку UTF-8 для вывода в консоли русских символов: иначе будут иероглифы
> ```
>
> В операционных системах семейства Linux могут быть свои заморочки с кодировкой. Если что-то работает не так, как ожидается, то заглядывайте в Google :)
