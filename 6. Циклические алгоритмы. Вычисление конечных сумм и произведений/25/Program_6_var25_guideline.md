# Пояснения по лабораторной работе №6

Эта работа учит вычислять выражения с конечными суммами и произведениями: вместо знака суммы или произведения мы пишем цикл, в котором накапливается результат.

> [!NOTE]
> Выражение вычисляется циклом по k от 1 до n: сумма накапливается сложением, произведение – умножением. Если при введённых n и x выражение не определено (например, логарифм неположительного числа или корень из отрицательного), результат не является конечным числом, и программа сообщает об этом. Значение π получаем как `acos(-1.0)`. Программа проверяет, что итог – конечное число; если в формуле есть логарифм, то при x = 0 он обращается в минус бесконечность, а деление на неё даёт нуль, поэтому для таких x результат нужно воспринимать с осторожностью.

> [!NOTE]
> Корень степени k из e^(k+1) равен e^((k+1)/k).

Итак, разберём код решения:
```c
#include <stdio.h> // Подключение библиотеки для ввода/вывода
#include <math.h> // Подключение библиотеки для математических функций
#include <windows.h> // Подключение модуля windows.h для установки кодировки вывода

int main() { // Объявляем главную функцию
    SetConsoleOutputCP(CP_UTF8); // Устанавливаем кодировку UTF-8 для вывода русских символов в консоль
    int n; // Объявляем количество членов n
    double x; // Объявляем аргумент x

    printf("Введите n: "); // Запрашиваем n
    scanf("%d", &n); // Считываем n
    if (n < 1) { // Проверяем, что n положительно
        printf("Число n должно быть положительным.\n"); // Сообщаем об ошибке
        return 1; // Завершаем программу с кодом ошибки 1
    }
    printf("Введите x: "); // Запрашиваем x
    scanf("%lf", &x); // Считываем x

    double factor = sqrt(exp(x / n)); // Множитель √(e^(x/n)) перед суммой
    double sum = 0; // Сумма членов
    for (int k = 1; k <= n; k++) { // Перебираем k от 1 до n
        sum += atan(x - k / (k + 1.0)) / exp((k + 1.0) / k); // Добавляем очередной член к сумме
    }

    double result = factor * sum; // Вычисляем значение выражения

    if (isfinite(result)) { // Если значение определено...
        printf("\nРезультат: %lf\n", result); // ...выводим результат
    } else { // Иначе...
        printf("\nРезультат: не определён\n"); // ...сообщаем, что при таких n и x выражение не определено
    }

    return 0; // Завершаем программу с возвращением 0
}
```

> Если Вы используете не Windows, а, например, macOS, то проблем с кодировкой быть не должно – в таком случае игнорируйте следующие строки:

> ...
>      SetConsoleOutputCP(CP_UTF8); // Устанавливаем кодировку UTF-8 для вывода в консоли русских символов: иначе будут иероглифы
> ```
